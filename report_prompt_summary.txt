sEMG 전처리·특징 데이터셋 관련 사용자 프롬프트 핵심 정리
작성 기준: 본 프로젝트 Codex 대화 중 sEMG 전처리와 특징 데이터셋 문제 해결에 직접 관련된 사용자 입력
정리 방식: 반복 표현과 세부 확인 질문은 합치고, 사용자가 요구한 문제·조건·산출물 중심으로 재구성

======================================================================
1. 데이터 구조 및 시행 구간 확인
======================================================================

- data 폴더의 CSV 구조와 sEMG 5채널을 확인한다.
- mark=1을 각 시행의 시작점으로 사용하고, 1,000 Hz 기준 5초인 5,000샘플을 한 시행으로 처리한다.
- 참가자, 팔꿈치 각도 30°·60°, 동작별 데이터 구성을 확인한다.
- 각 파일의 mark 간격과 근활성 구간 차이를 참가자·동작별로 비교한다.

핵심 목적:
이후 필터링, 시간축 정렬, 윈도우 분할 및 데이터셋 생성이 동일한 시행 기준으로 수행되도록 원본 데이터 구조를 먼저 검증한다.

======================================================================
2. onset 기반 데이터 시간축 정렬
======================================================================

- 참가자와 시행마다 다른 근활성 시작점(onset)을 검출하여 모든 5초 시행에서 2.000초 위치로 정렬한다.
- onset 검출은 Ch2~4를 우선 사용한다.
- P1 순차 → P1 동시 → P2 순차 → P2 동시 순서로 검출하고, 모두 실패한 시행만 Ch1~5 전체 채널에 같은 단계형 검출을 적용한다.
- 전체 검출도 실패하면 onset을 임의로 지정하지 말고 이동하지 않은 채 수동 검토 대상으로 기록한다.
- 정렬은 시간 정규화나 리샘플링 없이 전체 5채널을 동일한 샘플 수만큼 평행 이동한다.
- 이동으로 생긴 앞쪽 또는 뒤쪽 빈 구간만 동일 참가자·동일 동작의 다른 시행에 있는 수정 전 원본 값의 평균으로 보완한다.
- 다른 참가자·동작의 데이터나 이미 보완된 값을 donor로 사용하지 않는다.
- 원본 CSV는 수정하지 않고 전처리 결과와 시행별 검출 단계, 이동량, 보완 구간, fallback 사용 여부 및 QC 항목을 기록한다.
- 전체 파일과 시행을 다시 검증하여 기본 채널 검출 수, fallback 복구 수, 최종 실패 수를 보고한다.

정렬 이유와 목적에 포함할 내용:

1) 시행별 근활성 시작 시점 차이를 보정한다.
2) 참가자·각도·동작·반복 시행을 동일한 시간 기준에서 비교한다.
3) 평균 및 분포 분석에서 활성 증가·최대·감소 구간이 흐려지는 문제를 줄인다.
4) 모델이 실제 근활성 패턴 대신 시작 시간 차이를 학습하는 문제를 줄인다.
5) 전체 채널을 같은 양만큼 이동하여 원본 파형과 채널 간 시간 관계를 보존한다.
6) 불가피한 빈 구간만 제한적으로 보완하여 원본 정보 변형을 최소화한다.
7) fallback 사용 시행과 비정상적으로 빠른 onset 시행은 별도 QC 대상으로 표시한다.

======================================================================
3. sEMG 필터 구현 및 검증
======================================================================

- 2주차 실습 기준으로 sEMG 필터링 코드를 작성한다.
- 60 Hz 전원선 잡음 제거를 위한 notch filter를 적용한다.
- 이어서 20~450 Hz 4차 Butterworth band-pass filter를 적용한다.
- 위상 지연을 줄이기 위해 filtfilt를 사용하고, 5채널에 동일하게 적용한다.
- 실제 프로젝트 신호를 사용해 필터 적용 전후를 비교한다.

======================================================================
4. 분석 구간 절단과 윈도우 생성
======================================================================

- 필터링된 시행에서 1.5초 지점부터 2초, 즉 2,000샘플을 분석 구간으로 자른다.
- 윈도우 길이는 200 ms(200샘플), hop은 100 ms로 설정하여 50% overlap을 적용한다.
- 실제 실행 결과로 세그먼트 배열, 전체 윈도우 배열, 첫 윈도우 및 특징 벡터의 모양을 출력한다.
- 시행당 윈도우 수가 19개가 되는지 확인한다.

======================================================================
5. 시간영역 특징 구현
======================================================================

- 각 (200, 5) 윈도우에서 채널별 시간영역 특징을 계산하는 td_features 함수를 구현한다.
- 사용할 특징은 RMS, MAV, WL, ZC, SSC이다.
- 5개 특징 × 5개 채널을 연결하여 25차원 특징 벡터를 생성한다.
- ZC에는 작은 변화에 의한 잡음성 영교차를 줄이기 위한 임계값을 적용한다.

======================================================================
6. 시행 단위 학습·테스트 분할과 누수 방지
======================================================================

- 겹치는 윈도우가 학습셋과 테스트셋에 동시에 들어가는 데이터 누수를 방지한다.
- 먼저 mark 기준으로 모든 시행 목록과 클래스 라벨을 수집한다.
- 윈도우를 만들기 전에 시행 단위로 학습·테스트 데이터를 8:2 층화 분할한다.
- 분할된 각 집합 내부에서만 필터링, 구간 절단, 윈도우 생성 및 특징 추출을 수행한다.
- StandardScaler는 학습 데이터로만 fit하고 테스트 데이터에는 transform만 적용한다.

======================================================================
7. 데이터셋 생성 결과 검증
======================================================================

- 정렬된 전체 CSV에서 최종 특징 데이터셋을 생성한다.
- 전체 시행 수, 학습 시행 수, 테스트 시행 수를 확인한다.
- 학습·테스트 특징 배열과 라벨 배열의 크기를 확인한다.
- 8개 클래스별 학습·테스트 윈도우 수를 집계하고 분포가 균등한지 검증한다.

======================================================================
8. 200 ms 윈도우와 50% overlap의 설정 근거
======================================================================

- 200 ms 윈도우를 선택한 기술적 이유를 설명한다.
- 50% overlap을 선택한 기술적 이유를 설명한다.
- 200 ms는 시간영역 특징을 안정적으로 계산할 표본 수를 확보하면서 국소적인 근활성 변화를 보존한다는 점을 포함한다.
- 50% overlap은 100 ms마다 특징을 갱신하여 시간 해상도를 높이고, 활성 경계가 창 사이에 걸려 손실되는 문제를 줄인다는 점을 포함한다.
- overlap으로 생성된 유사 윈도우의 누수 문제는 시행 단위 선분할로 방지했음을 함께 설명한다.

======================================================================
통합 핵심 프롬프트
======================================================================

프로젝트의 실제 sEMG 코드와 데이터를 기준으로 전처리 및 특징 데이터셋을 검증하라. mark 기준 5초 시행에서 onset을 검출하여 2초로 시간축 정렬하고, 전체 5채널을 동일하게 평행 이동하며 빈 구간만 같은 참가자·동작의 다른 원본 시행 평균으로 보완하라. 60 Hz notch와 20~450 Hz band-pass 필터를 적용하고 전후 스펙트럼을 비교하라. 1.5초부터 2초 구간을 자른 뒤 200 ms 윈도우와 50% overlap으로 분할하고, RMS·MAV·WL·ZC·SSC의 25차원 특징을 생성하라. 겹치는 윈도우의 누수를 막기 위해 시행 단위로 먼저 8:2 층화 분할하고 scaler는 학습셋으로만 적합하라. 학습·테스트 샘플 수와 클래스별 분포를 검증하라.
