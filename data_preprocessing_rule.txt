sEMG 근활성 구간 정렬 전처리 규칙

1. 시행 기준

- 각 시행은 mark를 기준으로 한 5초 구간으로 정의한다.
- 샘플링 주파수가 1,000 Hz인 경우 시행당 길이는 5,000샘플이다.
- 시행을 별도 파일로 분할하지 않고 하나의 연속 CSV 파일로 유지한다.
- 전처리 전에 mark 간격과 각 시행의 샘플 수가 일정한지 확인한다.

2. onset 검출 기준

- 1차 onset 검출에는 채널 2~4를 사용한다.
- 각 시행의 mark 직전 1초를 baseline으로 사용한다.
- 첫 시행처럼 mark 직전 1초 baseline이 부족한 경우에는 같은 파일의 baseline이 충분한 다른 시행들에서 계산한 채널별 임계값의 중앙값으로 부족한 시행의 임계값을 정한다.
- 신호 포락선은 200 ms 후행 RMS로 계산하고, onset 검색 범위는 시행의 mark 이후 0~4초로 한다.
- P1 임계값은 baseline RMS의 '평균 + 5 표준편차'로 계산한다.
- P2 임계값은 baseline RMS의 '중앙값 + 5 × 1.4826 × MAD'로 계산하며, P1 검출이 모두 실패한 경우에만 사용한다.
- 순차 판정에서는 각 채널이 임계값을 최소 100 ms 동안 연속 초과하는 활성 run을 찾는다. 서로 다른 두 채널의 활성 run 시작점 차이가 300 ms 이내인 가장 이른 조합을 찾고, 두 시작점 중 더 이른 지점을 onset으로 판정한다.
- 동시 판정에서는 대상 채널 중 최소 2개 채널이 임계값을 동시에 초과하는 상태가 최소 100 ms 지속되는 최초 지점을 onset으로 판정한다.
- 1차 Ch2~4 검출은 'P1 순차 → P1 동시 → P2 순차 → P2 동시' 순서로 적용하며, 먼저 성공한 단계의 onset을 채택한다.
- Ch2~4의 네 단계가 모두 실패한 시행에 한해서만 Ch1과 Ch5를 추가한 전체 Ch1~5 채널에 같은 'P1 순차 → P1 동시 → P2 순차 → P2 동시' 순서를 적용한다.
- Ch2~4에서 성공한 onset은 전체 채널 결과로 다시 계산하거나 대체하지 않는다.
- 전체 채널 fallback에서도 순차 판정을 먼저 적용한다. 단순 동시 2-of-5 판정만 사용하지 않는다.
- 전체 채널 단계까지 모두 실패하면 해당 시행에 onset을 강제로 2초로 지정하지 않고 신호를 이동하지 않으며 수동 검토 대상으로 기록한다. 엄격 모드에서는 오류로 중단한다.
- 원본 CSV의 기존 onset 위치를 그대로 사용하지 않고, 모든 시행에 동일한 기준을 적용하여 onset을 다시 검출한다.
- 전체 데이터에 적용할 때는 필터링 방법, RMS 계산 구간, baseline 범위 및 임계값 산정 방법을 모든 참가자와 동작에 동일하게 적용하고 기록한다.
- 시행별로 검출 단계, 전체 채널 fallback 시도·사용 여부, 기여 채널, 두 채널 onset 차이, 최종 onset 및 QC 여부를 기록한다.
- 전체 채널 fallback으로 검출된 시행과 onset이 100 ms 미만인 시행은 자동 정렬 후에도 별도 QC 대상으로 표시한다.

3. 근활성 시작 목표 위치

- 각 5초 시행에서 근활성 시작점을 시행 시작 후 정확히 2.000초에 배치한다.
- 샘플링 주파수가 1,000 Hz이면 목표 위치는 mark + 2,000샘플이다.
- 위 검출 체인에서 onset이 성공적으로 검출된 시행에만 시간축 정렬을 적용한다.
- 시행별 이동량은 다음과 같이 계산한다.

  이동량 = 2,000 - 원래 onset의 시행 내 샘플 위치

- onset이 2초보다 빠르면 전체 채널 신호를 뒤로 이동한다.
- onset이 2초보다 늦으면 전체 채널 신호를 앞으로 이동한다.

4. 신호 이동 원칙

- 시간축 방향의 평행 이동만 수행한다.
- 신호를 늘이거나 줄이는 시간 정규화, 리샘플링 또는 파형 보간은 수행하지 않는다.
- 이동 후 남는 신호값은 원본 값을 그대로 사용한다.
- 평균값을 사용하는 범위는 이동으로 인해 데이터가 비는 구간으로 제한한다.
- onset 판정에 기본 Ch2~4 또는 fallback Ch1~5를 사용하더라도 이동은 전체 5채널에 동일하게 적용하여 채널 간 시간 관계를 보존한다.

5. 부족 구간 처리

- 첫 시행처럼 선행 데이터가 부족한 경우 부족한 길이만큼만 평균값으로 채운다.
- 각 시행의 신호 이동은 해당 시행의 mark부터 mark + 5초까지의 원본 신호 안에서만 수행하며, 인접 시행의 신호를 이동 원본으로 복사하지 않는다.
- 평균은 동일 참가자·동일 동작의 다른 시행 원본에서 각 시행 mark를 기준으로 동일한 source offset에 해당하는 값을 찾아 채널별로 계산한다.
- 앞쪽 부족분은 다른 시행의 동일한 음수 source offset(mark 직전 구간), 뒤쪽 부족분은 다른 시행의 동일한 5초 이후 source offset을 사용한다.
- 평균 보완값은 항상 수정 전 원본 CSV에서만 계산하며, 다른 시행에 이미 삽입한 평균값을 다시 donor로 사용하지 않는다.
- 현재 작성된 샘플에서는 첫 시행 앞쪽 130샘플, 즉 0.130초만 평균값으로 채웠다.
- 평균 구간 이후의 신호는 원본 값을 그대로 이동하여 사용한다.
- 이동 후 5초 범위를 벗어나는 반대쪽 끝부분은 제거한다.
- onset이 2초보다 늦어 신호를 앞으로 이동할 때 발생하는 시행 뒤쪽 부족 구간도 선행 데이터가 부족한 경우와 동일하게 처리한다.
- 동일 source offset의 원본 donor가 하나도 없으면 임의 값으로 채우지 않고 오류로 중단한다.

6. 평균값의 숫자 정밀도

- 평균으로 채운 값은 원본의 채널별 숫자 정밀도를 따른다.
- 동일 시간 위치의 2번째 이후 시행 값을 참조하여 채널별 소수 자릿수를 결정한다.
- 부동소수점 연산으로 발생한 불필요한 긴 소수 꼬리는 제거한다.
- 반올림은 부족 구간에 삽입되는 평균값에만 적용하며, 그 뒤의 원본 신호값은 변경하지 않는다.

7. 참가자 및 동작 간 데이터 혼합 방지

- 부족 구간 평균을 계산할 때 다른 참가자나 다른 동작의 신호를 혼합하지 않는다.
- 동일 참가자·동일 동작의 다른 시행만 평균 계산에 사용한다.
- 머신러닝 학습용 데이터에서는 학습·검증·시험 데이터 분할 후 학습 데이터만으로 평균값을 산출한다. 시행 단위로 분할한 연속 파일에서는 기준 mark뿐 아니라 실제 참조 원본 샘플도 학습 시행의 5초 범위에 속하는지 확인하여 인접한 검증·시험 시행의 값이 섞이지 않게 한다.

8. 원본 및 메타데이터 보존

- 원본 CSV 파일은 수정하지 않는다.
- 전처리 결과 파일명은 '원본파일명_pre.csv' 형식으로 지정한다.
- 전처리 결과는 data/data_pre 경로에 저장한다.
- 평균으로 채운 구간, 신호 이동량 및 잘린 구간을 기록하여 처리 내역을 추적할 수 있게 한다.
- time, mark 및 onset 값은 정렬된 신호와 일관되게 유지하거나 갱신한다.
- 수정 대상이 아닌 신호값은 원본과 수치적으로 동일해야 한다.

9. 전처리 후 검증 항목

- 각 시행의 길이가 정확히 5,000샘플인지 확인한다.
- mark 간격이 정확히 5초인지 확인한다.
- 동일한 Ch2~4 우선·전체 채널 fallback 검출 체인으로 다시 찾은 onset과 기록된 이동량이 일관되는지 확인한다.
- 정렬된 CSV의 onset 표지가 시행 시작 후 2.000초인지 확인한다.
- 모든 채널이 동일한 샘플 수만큼 이동했는지 확인한다.
- 평균값이 부족 구간에만 삽입되었는지 확인한다.
- 평균 구간 이후의 신호값이 원본과 동일한지 확인한다.
- 잘린 앞쪽 또는 뒤쪽 구간의 길이가 계산된 이동량과 일치하는지 확인한다.
- onset 검출 실패, 전체 채널 fallback 사용, onset 100 ms 미만 및 baseline 임계값 대체가 발생한 시행을 별도로 표시한다.
- 참가자별·동작별 onset 이동량과 결측 보완 길이를 비교하여 비정상 시행을 확인한다.

10. 핵심 원칙

Ch2~4의 단계형 검출을 우선 적용하고, 네 단계가 모두 실패한 시행에만 Ch1~5 전체 채널에 동일한 단계형 검출을 적용한다. 검출에 성공한 근활성 시작점을 각 시행의 2초 위치로 평행 이동한다. 이동으로 인해 비는 구간만 동일 참가자·동일 동작의 다른 시행에서 구한 채널별 평균값으로 채우며, 그 밖의 원본 파형에는 손대지 않는다. 전체 검출 단계가 실패한 시행은 강제로 정렬하지 않고 수동 검토 대상으로 남긴다.

11. 전체 채널 fallback 재검증 결과

- 원본 64개 파일, 총 1,920개 시행을 대상으로 재검증하였다.
- Ch2~4 단계형 검출은 1,918개 시행을 검출하고 2개 시행에서 실패하였다.
- 전체 채널 fallback은 남은 2개 시행을 모두 P1 순차 단계에서 복구하여 최종 1,920개 시행을 검출하였다.
- 복구된 시행은 d_30 pro 6회(Ch1·Ch5, onset 1,603 ms)와 h_60 pro 18회(Ch4·Ch5, onset 1,269 ms)이다.
- 최종 실패율은 0%였고, onset 100 ms 미만 QC 시행은 54개로 fallback 추가 전과 동일하였다.
- 정답 onset 라벨이 없으므로 실패율 0%는 검출 완전성을 의미하며 생리학적 onset 정확도 100%를 의미하지 않는다.
